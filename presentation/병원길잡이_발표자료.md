## 슬라이드 2: 서비스 소개

### 병원길잡이란?

AI 기반으로 환자 맞춤형 검사 안내문을 자동 생성하고,
병원 내 검사실 위치와 이동 경로까지 안내하는 통합 서비스

**핵심 가치**
- 환자: 복잡한 병원 내 이동을 쉽고 편하게
- 병원: 안내 업무 자동화로 효율 향상
- 통합: 여러 병원에서 하나의 플랫폼으로 사용 가능

---

## 슬라이드 3: 문제 정의 / 프로젝트 목표 / 대상자

### 문제 정의

| 문제 | 설명 |
|------|------|
| 복잡한 병원 절차 | 예약 → 접수 → 검사 → 진료까지 절차가 복잡하여 환자가 혼란을 겪음 |
| 대형병원 구조 난이도 | 대형병원은 구조가 복잡하여 검사실과 진료실을 찾기 어려움 |
| 정보 분산 | 병원 홈페이지마다 기능이 흩어져 있어 필요한 정보를 찾기 어려움 |

### 프로젝트 목표

- AI를 활용한 맞춤형 검사 안내문 자동 생성
- 병원 내 검사실 위치 안내 (층별 평면도 + 핀 표시)
- 병원 관계자용 관리 시스템 제공

### 주요 대상자

- 대형병원 방문 환자 (특히 40대 이상)
- 병원 관계자 (간호사, 접수 직원)

## 슬라이드 4: 주요 기능 (환자용)

### 환자용 서비스

**1. AI 검사 안내문 생성**
- 환자별 검사 순서, 위치, 주의사항을 자동으로 정리
- 한 장의 안내문으로 모든 검사를 한눈에 확인

**2. 검사실 위치 안내**
- 층별 평면도에 목적지 핀(📍) 표시
- Amazon Bedrock AI가 검사실 위치 자동 추측

**3. 카카오톡 / PDF 전달**
- 생성된 안내문을 카카오톡으로 환자에게 즉시 공유
- PDF 다운로드 및 인쇄 가능

**4. 병원 가이드 앱 연동**
- 실내 길찾기 웹앱과 연계하여 상세 이동 경로 안내

---

## 슬라이드 5: 주요 기능 (관리자용)

### 병원 관계자용 관리 시스템

**1. 대시보드**
- 오늘 예약 환자 수, 안내문 생성 현황, 출력 현황 한눈에 확인

**2. 예약 캘린더**
- 날짜별 예약 환자 목록 조회
- 환자 상세 정보 즉시 확인

**3. 안내문 / 출력 관리**
- 안내문 생성 상태 추적 (미생성 / 생성)
- 출력 상태 추적 (미출력 / 출력 완료)
- 필터 (날짜, 진료과, 시간) + 페이지네이션

**4. 데이터 관리**
- 엑셀 업로드로 환자 데이터 일괄 등록
- 환자 직접 등록 기능
- AWS S3 연동으로 실시간 데이터 동기화

## 슬라이드 6: 시스템 아키텍처

### 기술 스택 및 구조

```
[프론트엔드]          [클라우드 (AWS)]              [외부 서비스]
React + Vite    →    Amazon S3 (데이터 저장)        카카오톡 공유
Vercel 배포     →    AWS Lambda (서버리스)          
                →    Amazon Bedrock (AI)           
                →    API Gateway (API 연결)        
```

| 구분 | 기술 |
|------|------|
| 프론트엔드 | React, Vite, React Router |
| 배포 | Vercel |
| 데이터 저장 | AWS S3 (CSV) |
| AI | Amazon Bedrock (Claude Haiku 4.5) |
| 서버리스 | AWS Lambda + API Gateway |
| 안내문 | html2canvas + jsPDF |
| 공유 | Kakao JavaScript SDK |

## 슬라이드 7: 향후 개선 방향

### 향후 개선 계획

**1. 실내 경로 안내 고도화**
- SVG 기반 평면도 도입으로 정확한 경로 표시
- 실시간 대기 인원 연동

**2. 알림톡 자동 발송**
- 사업자 등록 후 카카오 알림톡 연동
- 전화번호 기반 자동 발송 (현재는 수동 공유)

**3. 다국어 지원**
- 외국인 환자를 위한 영어/중국어 안내문 생성

**4. 다병원 확장**
- 병원별 평면도 업로드 → AI가 자동 분석
- 통합 플랫폼으로 여러 병원에서 사용 가능

**5. 환자 앱 개발**
- 모바일 앱에서 실시간 길안내
- 검사 진행 상태 알림
